⚠️ Common Issues & Solutions

Login Issues:

  • Problem: Login fails or shows errors
  • Solution: Clear browser cache (Ctrl+Shift+R) or use incognito mode
  • Alternative: Try different credentials from the table above

Changes Not Showing:

  • Problem: Updates not visible in production
  • Solution: Ensure you're using the correct URL: dentist-portal-3.emergent.host
  • Check: Verify deployment was done on "Careflow 31" app, not other deployments

PDF Issues:

  • Problem: PDF opens and closes immediately
  • Solution: Check browser popup blocker settings
  • Alternative: Use incognito mode to bypass popup blockers

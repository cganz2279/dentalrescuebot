<product_requirements>
The application, DentalRescueBot, provides post-operative dental care information, derived from 80+ PDF documents, as a B2B SaaS platform for dentists. Dentists manage and assign these instructions. Key features include content search, PDF download, branding (DentalRescueBot logo, The OnCall Bot LLC), SaaS elements (authentication, multi-tenancy, practice registration, SamCart payment integration), and an admin dashboard for practice/patient/staff management. Crucially, the app is for dentists and administrators only; patients receive printed instructions, not direct access. Sales and thank you pages are hosted on WordPress, which also embeds the dental app's login and admin interfaces. Recent work has focused on fixing a critical database misconfiguration, enabling core dashboard actions (view, edit, print procedures), and enhancing PDF generation to match the professional in-app view.
</product_requirements>
